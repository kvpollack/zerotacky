# Astra audit: 11/4–11/5 builds and hand redraws

Audit target: main `b6db078b` = v2 `f3a5deee` (Vercel preview). Feature 3 `feed3356`, feature 4 `6d54358e`, production OG fix `1a3b9f8f`. Read on 2026-11-05. Scope is the [as-is brief](astra-brief-2026-11-05-builds-and-redraws.md). No application source was changed or pushed.

## Verdict

**Hold the build for four customer-facing issues.** The gym directory reveals an unlisted, results-submitted meet through `?show=`, the OG image URL is not the image actually advertised to social crawlers, long titles collide with card details, and the new pen keys have no visible keyboard focus outline. A direct owner save also accepts an invalid spec that its editor rejects; treat this as a fifth hold until the save boundary is fixed. These are separate from the clean 588-test baseline.

## 1. Feature 3: structured event spec

- **Real editor round trip:** created an unlisted staging meet `astra-1105-audit`, added “Astra Full Spec,” and saved every spec field. Values were Other / “Audit frame” / 50.5 ft, Belt and Chalk allowed, Straps and Tacky disallowed, `https://example.com/audit`, and “Audit all fields” notes. The scorer's MeetSetupSheet (no promoter host) opened the seeded Keg event with a spec, saved, reloaded, and kept that spec in offline state. The 588-test suite includes scoring regressions; no scores were changed in staging.
- **Validator payloads (local exact helper and, where indicated, staging):** `{'implement':'other'}` → describe implement; `{'courseFeet':0}`, `5281`, `-1` → range error; `1.5` → accepted; `0.01` and `1.25` → accepted despite the normalization/step problem BR-08; `{'allowed':['tacky'],'notAllowed':['tacky']}` → conflict; `{'videoUrl':'javascript:void(0)'}`, `'data:text/plain,audit'`, `'youtube.com/watch?v=x'` → http(s) error; a 502-character URL (`https://example.com/` plus 482 `a`s) → 500-character error; `{'notes':'n'×281}` → 280-character error. The hand-built RPC payload had `spec={'implement':'log','allowed':['tacky'],'notAllowed':['tacky'],'videoUrl':'javascript:void(0)'}` and **persisted** on the disposable meet (BR-05). The editor's native number/url fields may also reject certain values before reaching helper validation; helper and server were checked separately.
- **Weights and spec display:** the real Iron Harbor show prints its Yoke line, video link, and supplied kg cells. The pure `eventWeightDisplay` test printed 225 lb as **102 kg**, 226 lb as **103 kg**, 180 lb light as **82 kg**; zero prints no kg, 1 lb prints 0 kg (BR-08). A division with no weight prints no kg, a callout expressed as “100 kg” stays as-is without another conversion, and an event with spec but no division weights prints a spec line without inventing a weight. `divisionWeights` is documented as pounds; the builder has no separate kg-entry mode.
